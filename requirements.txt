# Astra AI Agent — runtime dependencies.
#
#   pip install -r requirements.txt
#
# FastAPI + uvicorn are the only web server: `python3 run.py` launches the
# ASGI app in astra/fastAPI.py, which serves the shared router in
# astra/web.py. There is no stdlib http.server path any more.
#
# Everything else the agent uses is the Python 3.9+ standard library
# (urllib, sqlite3, threading, ...), so there is nothing else to install.
#
# ── Termux/Android ─────────────────────────────────────────────────────
# pydantic 2 ships a compiled Rust core and publishes no Android wheel, so a
# plain `pip install fastapi` tries to build it from source. Install the
# pure-Python path instead:
#
#   pip install "fastapi<0.119" "uvicorn>=0.27" "pydantic<2"
#
# ── optional extras (uncomment only what your setup needs) ─────────────
#
# Real Playwright browser for the BrowserManager subsystem (optional).
# Without it the browser tools report "unavailable" honestly — the agent
# still works. Install then run:  python -m playwright install chromium
# playwright>=1.40
#
# `requests` — never required by the core (urllib is used), but handy for
# writing your own plugin adapters / one-off scripts against external APIs.
# requests>=2.31
fastapi>=0.110
uvicorn>=0.27
